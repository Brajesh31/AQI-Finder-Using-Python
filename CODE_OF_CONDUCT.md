# 🤝 Code of Conduct

## Our commitment

The AQI Finder project welcomes constructive participation from people with different backgrounds, experience levels, and perspectives. Contributors are expected to communicate respectfully and focus criticism on ideas, code, and evidence rather than individuals.

## Expected behaviour

- Be respectful, patient, and inclusive.
- Explain technical disagreement with evidence and clear reasoning.
- Accept constructive feedback.
- Keep discussions relevant to the project.
- Respect privacy when discussing user locations, provider tokens, or environmental-health information.
- Help newcomers understand repository conventions without dismissive language.

## Unacceptable behaviour

Harassment, discrimination, threats, personal attacks, doxxing, intimidation, deliberate disruption, and misuse or exposure of credentials or private location data are not acceptable.

## Scope

This code applies in repository issues, pull requests, code reviews, project discussions, and other spaces where someone is representing or participating in the project.

## Reporting

Report concerns privately through the contact route available from the maintainer's GitHub profile: [@Brajesh31](https://github.com/Brajesh31). Include relevant context and links. Do not post private personal information or secrets in a public issue.

## Enforcement

Reports will be reviewed by the maintainer. Actions may include a reminder, removal of inappropriate content, temporary restriction from discussions, or permanent exclusion from project spaces depending on severity and recurrence.

Retaliation against a person who raises a concern in good faith is not acceptable.
