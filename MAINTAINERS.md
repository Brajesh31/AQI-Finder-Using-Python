# 👥 Maintainers

## Responsibilities

The maintainer is responsible for keeping project scope accurate, reviewing code and documentation changes, protecting provider credentials, addressing security reports, and ensuring release notes do not overstate tested functionality.

## Requesting review

Open a focused pull request with the problem, scope, test evidence, and documentation updates. For architectural changes, open an issue or add an ADR before implementation. Use the private reporting route in [SECURITY.md](SECURITY.md) for vulnerabilities.

This file lists project responsibilities, not a guarantee of response time or continuous support.
